# Integrations

**Test reports for third-party software used with mountx.**

mountx supports protocols that already have many clients. This section records tests with those clients. Each page names the tested version and explains what worked, what failed, and what was not tested.

These reports do not promise support. Use them to learn what to expect before you try the same setup.

## Pages

- [**celld**](/guide/integrations/celld) uses [`mountx/s3`](/transports/s3) as a shared bucket. [celld](https://github.com/denoland/celld) runs Cloudflare Workers and Durable Objects on your own machines.

## Clients covered elsewhere

Some client tests are documented on the page for their transport:

- **rclone**, the AWS CLI, the AWS SDKs, and presigned URLs: [S3](/transports/s3#quick-start).
- **`mount.nfs`, macOS `mount_nfs`, and the Linux 9P client**: [NFS](/transports/nfs) and [9P](/transports/9p).
- **`fusermount3`**: [FUSE](/transports/fuse).
- **QEMU and Firecracker guests**: [Virtual machines](/guide/vms).

## Report an integration

If you test other software with mountx, [open an issue](https://github.com/pithings/mountx/issues). Include the software version, the transport, and the exact error if something failed.
